# мт-cozʏcʀᴀғт Wiki

Website wiki Minecraft phong cách Dark Fantasy. Đây là bản khởi đầu tĩnh, chạy miễn phí bằng GitHub Pages.

## Xem thử trên máy
1. Giải nén file ZIP.
2. Mở `index.html` bằng Chrome, Edge hoặc Firefox.

## Đưa website lên mạng miễn phí bằng GitHub Pages
1. Đăng nhập hoặc tạo tài khoản GitHub.
2. Tạo repository mới, ví dụ `mt-cozycraft-wiki`.
3. Upload `index.html` vào thư mục gốc repository và Commit changes.
4. Vào **Settings → Pages**.
5. Trong **Build and deployment**, chọn **Deploy from a branch**.
6. Chọn branch `main`, folder `/(root)`, bấm **Save**.
7. Đợi GitHub xuất bản trang. Địa chỉ thường có dạng:
   `https://TEN-TAI-KHOAN.github.io/mt-cozycraft-wiki/`

## Chỉnh sửa
- Mở `index.html` bằng VS Code hoặc Notepad.
- Tìm tên server, nội dung mô tả, các mục Wiki rồi thay bằng dữ liệu thật.
- Các mục Boss, NPC, vật phẩm hiện là nội dung mẫu để bạn thay thế.
- Có thể thêm ảnh bằng thẻ `<img src="ten-anh.png" alt="...">` và upload ảnh cùng repository.

## Lưu ý
- GitHub Pages miễn phí cho website tĩnh; không có cơ sở dữ liệu hay tài khoản biên tập tích hợp.
- Không đưa mật khẩu, token hoặc thông tin riêng tư vào mã nguồn công khai.
- Đây là trang cộng đồng không chính thức, không liên kết với Mojang/Microsoft.
